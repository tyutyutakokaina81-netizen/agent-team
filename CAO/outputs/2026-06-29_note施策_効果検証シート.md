## ステップ0：いつ測るか

## ステップ3：判定の目安（code が分析します）
- **スキ率が上がった** → 写真＋締めが効いている。仕事系で効いてなければ写真を外す。
- **検索流入が増えた／ビューが伸びた** → タイトルKWが効いている。残り記事も同型に寄せる。
- **変化なし／下がった** → その施策は撤回 or 別案。**効かないものは正直にやめる**（A5の精神）。

## owner の最小アクション（これだけ）
1. 上の **比較A・B のどちらか1つ**でいいので、対象記事の数字を1〜2週後にこの表へ貼る（または code にコピペで渡す）。
2. code が差を計算し、「効いた型・効かない施策」を判定 → 効いた型に全記事を寄せ直す（撤回も含む）。

> **正直な要点**：ここから先の伸びは「制作」ではなく「この数字1回」で決まる。
> 数字が来れば最適化が始まり、来なければ全施策は未検証のまま据え置きになる。

## 比較D：2026-08-27公開6本の「型」検証（追加・CAO 2026-08-27）

**背景**: 8/27に強化版6本を公開（キュー刷新後の初公開成功）。従来の量産型（1,800字前後・単一トピック）と異なる**新しい型**を複数投入したので、どの型が伸びるかを測る。閲覧数が来たら下表を埋めて判定する（A1＝code側は閲覧数を見られない）。

### 測る仮説（どれが正しいか）
- **H1（長文×深掘り）**: 2,800〜5,500字の深掘り記事は、短文より滞在時間・スキ率が高い（読者の熱量が上がる）。
- **H2（実用ガイド型）**: 「2日完璧ガイド」等の実用・保存型は、エッセイ型より保存/検索流入が多い。
- **H3（実写サムネ）**: 実写サムネ付き（田んぼ）は、無サムネより初速ビューが高い。
- **H4（食×ハイパーローカル）**: コロッケ等「その土地だけ」の食は、一般的な食より海外反応（コメント/流入）が強い。

### 判定ルール（どう読むか）
- **H1**: 深掘り4本（コロッケ/氷見/高岡/2日ガイド）の平均スキ率 vs 従来量産型（比較B）の平均。深掘りが高ければH1採用＝**今後は本数より深さ**へ寄せる。
- **H2**: 「2日ガイド」の検索流入・スキ率が突出 → 実用ガイド型を月1本の柱に。
- **H3**: 田んぼ（実写）の初速ビューが無サムネ群を明確に上回る → **実写サムネ取得を全記事の標準**に（note-thumbnails Actionの検証済stem登録を進める）。
- **H4**: コロッケ/氷見のコメント・海外流入が非食を上回る → **食×ハイパーローカル**をクロスポストの主軸に。

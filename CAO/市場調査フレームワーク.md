# CAO 市場調査フレームワーク（能力強化版・2026-08-16）

> CAO の「市場調査・反響分析」能力を実体化する運用フレーム。North Star＝**海外読者を
> 高岡・氷見・富山の記事に到達させる**。調査は必ず「次の打ち手」に落とす（分析だけで終わらせない）。

## 0. 調査の原則（毎回確認）

- **一次情報を必ず途中で差し込む**（入れないと一般Web要約止まり）。WebSearchで実データ＋**出典明記**。
- **事実／推測／引用を区別**して書く。反証可能な仮説（「こう考えられる。ただし○○なら別」）。
- 誇張禁止（A5）。数値は「実測」か「仮置き」かを明示。**不都合な数字から逃げない**（自責）。
- **「ページ量産＝流入」ではない**：新設サイトのindex/順位の律速は**被リンク**。制作を増やす前に発見経路を診る。
- 出力は他役職が**即動ける形式**（誰が・何を・いつ）でファイルハンドオフ。

## 1. 競合スキャン手順（WebSearch プロトコル）

1. 競合セットを定義（例）：①海外向け日本ローカル文化ブログ/YouTube ②富山/北陸の観光・インバウンド発信
   ③"day trip from Kanazawa" 等の周遊系 ④note内の同ジャンル発信者。
2. 各競合から抽出：**ポジショニング／主要トピック／投稿頻度／エンゲージ signal（コメント・被リンク・検索順位）／言語／収益導線**。
3. **ギャップ分析**：競合が手薄／未カバーで、当社の一次観察（高岡住人視点）が刺さる領域＝勝ち筋候補。
4. 出力：`競合名｜強み｜弱み/ギャップ｜当社の取り得る差別化｜次の打ち手` の表で提示。

## 2. キーワード / 検索意図調査（海外SEO）

- 対象：英語の検索語（例 "Takaoka", "Himi", "Toyama travel", "Gokayama", "day trip from Kanazawa",
  "off the beaten path Japan", 季節×体験 等）。日本語圏はnote/国内用に切り分け。
- 各語について：**検索意図（情報/計画/購買）／競合の強さ／当社が勝てそうか**を3段階で評価。
- **indexの実測**：`site:` 検索や記事タイトル検索で、当社ページが**実際にindexされ順位が付いたか**を確認
  （「公開した」≠「発見された」）。indexされない主因は**被リンク不足**＝Quora/Reddit等の価値先行投稿を打ち手に。

## 3. チャネルROIランキング（実測で順位化）

各集客チャネルを「**実測流入**」で採点し、工数を上位へ寄せる。制作本数では採点しない。

| チャネル | 実測流入(仮/実) | 特性 | ROI順位の目安（実戦学び） |
|---|---|---|---|
| GitHub Pages 英語ガイド | | SEO/検索流入・本命 | 中〜高（被リンクが付けば伸びる） |
| KDP | | Amazon購買流入を借りる・本命 | 中〜高（レビュー律速） |
| Quora | | Google長期流入 | **最上位**（実戦で最良） |
| Reddit | | 被リンク/話題化 | 中（規約順守） |
| note | | 国内/warm-lead向き・海外に構造的に届きにくい | 国内用に限定 |
| X / Instagram（コールド） | | 拡散狙いだが冷たい客 | 劣後 |

→ 手順：①各チャネルの実測を集める（無ければ「仮置き」明示）②時間ROIで並べる③上位に工数集中を提言。

## 4. 反響分析（A/B・読者アナリティクス）

- データ源：note の閲覧数/スキ/コメント（owner共有時）＋ EN/KDP の反応。**正本＝`CAO/outputs/2026-06-29_note施策_効果検証シート.md`**。
- 手順：**閲覧/スキを題材・型（タイトル/冒頭/サムネ/カテゴリ）でクラスタ化 → 共通項ランキング → 上位1〜3を「効いた型」として強化、効かない施策（特に仕事系写真）は撤回**。
- A/B設計：**一度に1変数だけ**変える（タイトル型 or サムネ有無 or 冒頭パターン）。比較は同条件で。
- 評価は「鬼コンサル人格」で厳しく。**印象でなく数字**で優劣を言う。

## 5. 市場規模の軽量見積り（TAM-lite）

- ニッチの規模を「訪日客のうち北陸/穴場志向」×「英語で情報探索する層」で**桁感**を掴む（精密でなく意思決定用）。
- 公開統計（訪日客数・地域別・言語別）を WebSearch で取り、**出典と取得日を明記・ヘッジ**。断定しない。
- 使い道：どのキーワード/チャネルに賭けるかの**相対比較**（絶対値の主張には使わない）。

## 6. トレンド監視サイクル

- 週次：季節トピック（次の2〜4週で伸びる行事/食/風物）・競合の新しい打ち手・検索の話題。
- 月次：チャネルROIの再採点・「効いた型」の更新・被リンク獲得の進捗・KDP/Pagesのindex状況。
- アウトプットは短く。**「今わかったこと1行＋次の打ち手1つ」**を各役職へ。

## 7. ボトルネック診断（作れる側でなく詰まっている側を見る）

打ち手を出す前に、律速がどこかを判定する：
`制作（記事/ページ）` ／ `発見（index・被リンク・検索順位）` ／ `実行エンジン（Mac公開ワーカー稼働）` ／ `転換（CVR・レビュー・継続率）`。
→ 詰まりが「制作」以外にあるなら、**追加制作を勧めない**（ROIが低い＝誠実でない）。真のレバーを名指しする。

## 8. アウトプット様式

```
【事実】（実測・出典・取得日）
【考察】（反証可能な仮説・事実/推測の別を明示）
【提案】（誰が・何を・いつ／3シナリオがあれば松竹梅）
【ハンドオフ】→ CMO/CPO/CSO/CFO/CDO（ファイルで）
```

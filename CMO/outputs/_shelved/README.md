# _shelved — 公開しないと決めた記事

公開側の重複ゲート（`topic_conflict`）で既公開と同題材と判定され、
**キューに置いても毎回必ず失敗する**ものをここへ移す。消さずに残す。

| 記事 | 重なった既公開 | 判断 |
|---|---|---|
| 2026-08-25_氷見と高岡_港町と古都は何が違うのか | 富山2日完璧ガイド：氷見と高岡を2日で巡る旅程 | 題材「氷見と高岡」が同一。切り口（比較 vs 旅程）は違うが、**読者から見て同じ題材**なので出さない |
| 2026-08-25_高岡コロッケ_脇役を主菜にする食べ方 | 高岡コロッケ（2026-06-03 ほか） | 同題材。R26 も公開側も重複と判定する |

切り口が本当に別で出す価値があると判断したときは、
`bash ops/publish_today.sh --dup`（`--allow-topic-dup`）で個別に出す。

**なぜ原本ごと移すか**: `CMO/outputs/` に残したままだと R21 が「未投入の在庫」として数え続け、**実際には絶対に公開できない本数が在庫に混ざる**。数字が嘘になるので、出さないと決めたものはここへ移す。

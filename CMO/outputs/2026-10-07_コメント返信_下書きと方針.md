# note コメント返信 — 方針と下書き（2026-10-07）

## これは何か

オーナーから「コメントに返信して」と何度か言われているが、**code は note を見られない（A1）ので
文面がこちらに届いていない**。取得が走れば書けるが、待っているあいだに何も無いのは不誠実なので、
**届いた瞬間に出せる形**で型ごとの下書きを置く。実際のコメントが来たら、この型を土台に
**一件ずつ中身に合わせて書き直す**（そのまま貼らない。同じ文面を並べるとテンプレ＝A5違反になる）。

## 返信の方針

1. **必ず相手の言葉を1つ引き取る。** 「ありがとうございます」だけで終わらせない。
   どこに反応したのかが分かる一文を入れる。
2. **質問には答えられる範囲で答え、答えられないことは答えられないと書く。**
   調べていないことを調べたふりで書かない（A1・A5）。
3. **宣伝しない。** 自分の別記事を貼るのは、相手の話に本当に続きがあるときだけ。
4. **短くする。** 本文は長く書いているが、返信は3〜5行で足りる。長い返信は圧になる。
5. **英語のコメントには英語で返す。** 機械翻訳めいた言い回しを避け、本文と同じ調子で書く。
6. **同じ文面を2人に送らない。** 似た内容でも、相手の言葉が違えば書き出しを変える。

## 型①：記事を褒めてくれた（日本語）

> 例：「おもしろかったです」「知らなかった」

```
読んでくださってありがとうございます。
○○のところ、地元だと当たり前すぎて誰も説明しないので、
こうして「知らなかった」と言ってもらえると、書く意味があるなと思います。
```

※ ○○ には**その記事の具体的な箇所**を入れる。入れられないなら、その返信は書かない
（どこを読んだか分からないまま褒め返すのは、相手を見ていないのと同じ）。

## 型②：自分の土地の話をしてくれた

> 例：「うちの方では△△と言います」

```
△△というんですね。知りませんでした。
同じものに土地ごとに別の名前がついているのは、書いていてよく出てきます。
教えていただいた分、ひとつ増えました。ありがとうございます。
```

## 型③：質問された（答えられる）

```
ご質問ありがとうございます。
（答え）。ただ、これは自分の家でのやり方で、地域や家で違うと思います。
```

## 型④：質問された（答えられない）

```
ご質問ありがとうございます。
正直なところ、そこは自分でも分かっていません。
記事にも書いたとおり、確かめていないことは書かないようにしているので、
いずれ確かめられたら、そのときに書き足します。
```

※ **これを使うことを恐れない。** 知らないことを知らないと書くほうが、長い目では信用になる。

## 型⑤：訂正・指摘をもらった

```
ご指摘ありがとうございます。確かにそのとおりです。
本文を直しました（／確認して直します）。
助かりました。
```

※ **指摘が正しければ必ず本文を直す。** 返信だけして本文を放置しない。

## 型⑥：英語のコメント（褒め・感想）

```
Thank you for reading. The part about ○○ is something nobody here explains,
because everyone grew up with it — so it is genuinely useful to hear that it
read as new. I write one of these most days, mostly about ordinary things in Takaoka.
```

## 型⑦：英語のコメント（質問）

```
Good question. (answer.) That said, this is how it works in my own household —
it varies by region and by family, and I have not checked how widely it holds.
```

## 型⑧：答えられない英語の質問

```
Honestly, I do not know. I try not to write things I have not checked, and that is
one of them. If I find out, I will add it to the piece.
```

## 使ってはいけないもの

- 「ぜひ他の記事も読んでみてください」だけの返信（宣伝にしか見えない）
- 全員に同じ文面（**note の返信は他の読者からも見える**。並ぶとテンプレだと分かる）
- 絵文字の多用（本文の調子と合わない）
- 「〜させていただきます」の連発

## 実際に来たらやること

1. `ops/comments/pending.tsv` の行を Claude に渡す
2. **1件ずつ**中身に合わせて書く（この型は骨格として使うだけ）
3. `ops/comments/replies.tsv` に `status=READY` で書き込む
4. owner / cowork が note に投稿する（code は投稿できない＝A1）

# note コメント返信ガイドライン（2026-08-16）

> code は note にアクセスできない（A1）。**返信はowner/coworkが実施**。本ガイドは「誰が返しても
> 一貫して温かく・オンブランド・A5厳守」で返すための型。高岡住人「てつ」の声で。

## 基本トーン
- 温かく・謙虚・気取らない（富山弁の「きのどくな」的な、少し不器用なやさしさ）。
- **A5厳守**：誇張・断定をしない。知らないことは「詳しくは知らないのですが」と正直に。
- **North Star**：海外読者に高岡・氷見・富山を届ける。英語コメントには**英語で**同トーンで返す。

## 返信の型（1〜3文で短く）
1. **感謝**：読んでコメントをくれたことにひとこと。
2. **具体的に応じる**：相手のコメントの1点を拾って返す（コピペ感を出さない）。
3. **小さなGIVE**：地元の一言・補足・おすすめを添える（押し付けない範囲で）。
4. （任意）**さりげない継続**：「よかったらまた」程度。宣伝・勧誘はしない。

## やらないこと（禁止）
- 定型文のコピペ連発（A5＝テンプレNG）。同じ言い回しを続けない。
- 断定・過剰な約束（「絶対」「日本一」等）／政治・宗教・論争への深入り。
- **A4**：具体的な住所・番地・私的情報を書かない/聞き出さない（市/県レベルまで）。
- スパム/宣伝目的のコメント → 反応せずスルー、または一言だけ丁寧に。
- 批判・ネガティブなコメント → 防衛的にならず、誠実に短く。事実誤りは穏やかに訂正（出典があれば添える）。

## 例（雛形・そのままコピペしない＝必ず個別化）
- 称賛系(和)：「読んでくださってありがとうございます。◯◯、いいですよね。△△なんかも夏らしくておすすめです。」
- 質問系(和)：「ご質問ありがとうございます。□□については、私も詳しくは知らないのですが、◯◯だと聞いています。」
- 英語(称賛)：「Thank you for reading! Glad it resonated. If you ever visit, ◯◯ is worth a look too.」
- 英語(質問)：「Good question — I'm not fully certain, but locally it's said that ◯◯. Thanks for the interest!」

## 手順
1. cowork/owner が各記事の未読コメントを確認。
2. 上の型で個別に返信（英語コメントは英語）。
3. 返信内容・件数を `ops/outbox/` に一言報告（code が台帳/分析に反映）。
4. **有益なコメント（質問/要望/反響）はCAOの反響分析へ**（読者の関心＝次の題材ヒント）。

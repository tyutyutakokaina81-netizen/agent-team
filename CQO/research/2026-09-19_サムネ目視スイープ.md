## ここまでで分かった構造的な欠陥（30枚時点）

### ① R2d が「1枚が5記事」を ✅ と報告していた（修正済）
09-22 に「_verified 同士の共有も明細に出す」と直したが、**直したのは報告文だけで、
警報を出す側の集計は verified を取り除いたままだった**。
```python
_shared = [[st for st in v if st not in verified] for v in _groups.values() if len(v) >= 3]
_fallback = {st for v in _shared if len(v) >= 4 for st in v}   # ← 5本とも verified なら 0本
```
実測で **2枚が5記事ずつ**に配られていた：
- 夏野菜のかご → 庭の畑 / 家庭菜園 / とうもろこし / トマト / 無人販売所
- 海沿いの道 → 蜃気楼(2本) / 魚の宝庫 / 海水浴 / 有料note

配布数を **verified を含めた全体で数える**よう修正。4記事以上でかつ2本以上が採用済みなら BROKEN。

### ② REJECTED 登録は「これから引く画像」しか止めない
Marshall のビール缶は 09-22 に REJECTED_FILES へ入れたが、**すでに別 stem で採用されていた
コピーは残ったまま**で、枝豆の記事の見出しに今も出ている。
→ **REJECTED に入れたら、既存の jpg も名前ではなく中身(md5)で探して外す**必要がある。

■ 新しい診断が答えを出した
前回 run のログ:
  れんこん「蓮根 収穫」 → diag={'pages': 2,  'img': 0, **'mimes': {'application/pdf': 2}**}
  衣替え  「衣類 整理」 → diag={'pages': 12, 'img': 0, **'mimes': {'application/pdf': 12}**}

**候補枠12件すべてが PDF だった。** Commons の File 名前空間には PDF も入っていて、
この日本語の語では走査資料や報告書の PDF ばかりが返っていた。取得側で mime を弾くので
結果は「候補なし」。だが今までの診断は pages と img しか出しておらず、
**「pages:12 / img:0」という何も分からない表示**になっていた。

■ 直したこと
検索の時点で `filetype:bitmap` を付けて画像だけに絞る。
絞り込みで0件になった場合は**元のクエリで引き直す**退避路も入れた
（新しい絞り込みがそれ自体で全滅の原因になっては本末転倒なので）。
引き直したときは診断に `bitmap_filter_empty: True` が出る。

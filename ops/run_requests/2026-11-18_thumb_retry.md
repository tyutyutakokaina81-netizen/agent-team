# サムネ取得の実行依頼（2026-11-18 その2）

**目的**: 却下済みの jpg が残っていて取り直しの枠を塞いでいた4本を、もう一度取りにいく。

R31 が言っていた型＝**中身(md5)で落とした画像が、ファイルとして残ったまま**になっていると、
`fetch_thumbnails_wikimedia.py` は「jpg が在る記事」を飛ばすので、**取り直しが永久に走らない。**

今回の直接のきっかけは **踏切**（2026-10-29）。
却下した直後（19:19 の自動実行）に**同じ画像が戻ってきて jpg が再生成されていた**。
取得側の md5 ブロックは、**却下のコミットが届く前に走った回には効かない**。
→ **jpg を消してから Action を起こす**のが正しい順番。

消したもの（いずれも未採用＝見出しには使われていない）:
- 2026-06-19 御清水庵
- 2026-07-30 火を使わない夏ごはん
- 2026-08-02 みょうが
- 2026-10-29 踏切（ファイル名に駅名／A4・R30）

※踏切のファイル名は却下台帳の `file:` 列に入ったので、
  `_is_rejected_file` が**名前のほうでも**塞ぐようになっている（2026-11-15 に入れた仕組み）。

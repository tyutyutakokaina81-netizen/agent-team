# サムネ 2巡目（2026-11-01 の3本）

1巡目＝**押し入れ却下／牛たん却下／しいたけ候補ゼロ**。3本とも手を入れた。

- **押し入れ**: `押入れ` が**台湾の史跡**（辛志平校長故居）を引いた。
  → `故居`『請勿』『紀念館』『文物館』を **NON_JAPAN_HINTS に追加**。
  ★**漢字の語は、台湾に残る日本統治期の建物に届く。**
- **牛たん**: `牛たん` が**仙台駅の駅弁**を引いた。
  → `駅弁`『弁当』を **UNUSABLE_NAME_HINTS に追加**＋
  **`ops/placenames.py` に市名50語を追加**（県名は本文にあっても市名は無い、という穴）。
- **しいたけ**: 4語とも pages:0。→ **カタカナの `シイタケ` を先頭**にした。

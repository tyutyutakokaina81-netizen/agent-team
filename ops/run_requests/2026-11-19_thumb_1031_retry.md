# サムネ 2巡目（2026-11-19）

1巡目の結果＝**ひじき却下 / 芋煮却下 / ブロック塀は候補ゼロ**。3本とも語を直した。

- **ひじき**: 単体の `ひじき` が**海の岩で生えている状態**（褐色〜黄緑）を引いた。
  記事の芯「乾いても煮ても真っ黒」と正面から食い違う。
  → 単体と学名に流れる `鹿尾菜` を外し、**料理の語だけ**にした。
- **芋煮**: 単体の `芋煮` が**芋煮カレーうどん**（別の料理・白い丼に一人前）を引いた。
  **記事の芯「一人分が、無い」と正面から食い違う。**
  警戒していたのは会場パノラマのほうだったが、来たのは**派生料理**。
  → 単体を外し、**鍋・大鍋・椀**の文脈に閉じた。
- **ブロック塀**: 4語とも **pages:0**＝検索自体が空。日本語の語しか無く、
  Commons 側の説明文・カテゴリが英語なので当たらない。
  → **`japan` 付きの英語の語**を足した（`japan` が入ると日本判定の足切りが効くので、
  「英語の語＝海外の写真が来る」という従来の危険はここでは起きない）。

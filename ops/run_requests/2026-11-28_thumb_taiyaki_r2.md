# サムネ再取得（たい焼き・2巡目）

急須と出雲そばは1巡目で採用。残りは たい焼き。

| 記事 | 1巡目 | 直した理由 |
|---|---|---|
| たい焼き | `たい焼き` → **`クロワッサンたい焼き.jpg`**（三角形のクロワッサン生地で**魚の形が無い**） | ★★★**名前に題材名が入っていても、派生商品は形を捨てていることがある。検索語が題材名と一致していても、その題材を定義している特徴が写っているかを見る必要がある** → **ローマ字を先頭に**（`taiyaki` は派生商品名に使われにくい見込み） |

★**今日の収穫＝「ローマ字表記の固有名詞」が3本連続で効いた**（`chawanmushi` → `kyusu` → ※出雲そばは日本語で当たった）。

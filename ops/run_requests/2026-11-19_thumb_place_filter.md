# サムネ取得の実行依頼（2026-11-19・地名フィルタを入れたあと）

**取得の時点でファイル名の地名を見るようにした**ので、その状態で回す。

これまでは
- R30（check_requirements）が**採用したあと**に「記事に出てこない地名がファイル名にあるか」を数える
- 取得側は `_place_mismatch()` で**クエリ**しか見ず、**取れてきたファイル名は見ない**

という分担だったので、**取得は通って、採用の直前に人が目で落とす**ことを毎回やっていた。
却下台帳 351件のうち、**ファイル名の町名・駅名・施設名が理由のものが約30件**。

→ 地名の表を `ops/placenames.py` に1本化し、**取得側がダウンロードの前に同じ判定をする**
   ようにした（診断キーは `place_in_name`）。R30 も同じ表を読む。

これで止まるはずのもの（過去に人が目で落とした実例）:
生麦駅／三井野原駅・木次線／名掛丁／大字田吉947番地／Akasaka／八尾町西神通／白沙荘／
高尾山／船橋競馬場／道後温泉／金閣寺・銀閣寺／春日部／くらやみ祭り（府中）／郡山宿／沼津

**落としてはいけないほう**（開示済み）も守る:
記事名に地名がある／本文に漢字で書いてある（ファイル名はローマ字）／「※撮影地は県外」と断ってある。
回帰テスト＝`python3 ops/test_placenames.py`（11件・全部通る）。

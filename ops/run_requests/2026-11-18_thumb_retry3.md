# サムネ取得の実行依頼（2026-11-18 その3）

**目的**: 踏切のクエリを直したので、もう一度取りにいく。

踏切は2巡とも**ファイル名に駅名が入っていた**
（1巡目『生麦駅の踏切』／2巡目『木次線「三井野原駅」の駅舎と線路』）。
★★**クエリ『線路 踏切』は踏切ではなく駅を引く**＝2巡目は踏切が写ってすらいなかった。
⚠️さらに**4語中3語が2語クエリ**で数が出ていなかった（春菊と同じ型）。
→ **`遮断機` を単語で2番目に上げ、2語クエリを減らした**。
   遮断機は**踏切にしか無い物**なので、駅や線路一般には流れにくい見込み。

【方針変更】2026-09-23・オーナー確定。**サムネは全記事に必ず付ける。**

これまで code は「誤サムネより無サムネが正」という基準で運用していたが、これは code が
勝手に作ったもので、**9月の30本中11本が無サムネで公開されていた**。
指示は「毎日サムネつきで書く／目的は海外に届くこと」なので、この運用自体が誤りだった。

■ 新しい判定基準
  **題材が合っていれば採用する。** ぴったりの構図でなくてよい。
  - 例）白菜の記事に「畑で育っている株」→ **採用**（ずれている点は事実検証ノートに書く）
  - 例）石油ストーブの記事に「据置型のファンヒーター」→ **採用**（本文は携帯型だが器具としては同じ）
  落とすのは **明らかに別物** のときだけ:
  - そばの記事に束ねた乾麺（＝料理でも店でもない）
  - 豚汁の記事で椀に具が一切見えない
  - 本文と違う生き物・違う成長段階（成虫の話に幼虫）
  落としたら **必ず語を変えて取り直す**。無サムネで終わらせない。

■ 今回の対象（どちらも未公開・キューにある）
【1】石油ストーブ … 反射式ストーブ / 石油ストーブ / ストーブ 部屋 / 石油ストーブ 反射
  以前「外部タンク付きの据置型ファンヒーター」を落としたが、**新方針では採用でよい**。
  可能なら反射式（携帯型）を優先。無ければ据置型でも可。
  避けたいもの＝人物、メーカー名やモデル名が**大きく読める**もの、ガス/電気の暖房器具。

【2】白菜 … napa cabbage / Chinese cabbage / 白菜 / ハクサイ
  以前「畑で育っている株」を落としたが、**新方針では採用でよい**。
  可能なら丸のままの一玉か切った断面を優先。無ければ畑の株でも可。
  避けたいもの＝人物、値札や店名が読めるもの、キムチなどの加工品。

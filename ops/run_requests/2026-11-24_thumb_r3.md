# サムネ再取得（2026-11-24）

3本とも却下。語とフィルタを直した。

- **ほうれん草**: `ほうれん草 おひたし` が**塩サバ定食**を引いた。
  ★★**料理名を足すと、その料理が載っている「食卓ごと」に届く**＝題材が小鉢に落ちる。
  → 料理名を外し、素材そのものと `spinach japan` に寄せた。
- **牛たん**: `タン塩` が**麺屋レノンの塩ラーメン**を引いた。
  ★★**2文字の語は、店の品名の一部にゆるく一致する**（`塩` が当たった）＝短い語ほど割れやすい。
  → `タン塩` を外し、`beef tongue japan` を入れた。
- **佐世保バーガー**: `hamburger japan` が**ビッグマックを2回**（別ファイルの同じ商品）。
  → `big mac`『mcdonald』等の**外食チェーン名を UNUSABLE_NAME_HINTS に追加**（検証済み）。
  語順も `手作りハンバーガー` を先頭にした。

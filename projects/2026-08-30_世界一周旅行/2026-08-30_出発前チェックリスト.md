# 出発前チェックリスト（180日・世界一周）

作成: 2026-08-30 ／ 「出発日 D」からの逆算で並べてある

## D−12ヶ月：土台をつくる

- [ ] **積立の自動化**：給与口座とは別に旅行専用口座を作り、毎月の積立を自動振替にする（意志に頼らない）
- [ ] **パスポートの残存期間を確認**：多くの国が**入国時に残存6ヶ月以上**を求める。残り1年半を切っていれば更新しておく
- [ ] **パスポートの査証欄の残ページ数を確認**：本ルートは入出国スタンプが20個以上つく。**空きページが4ページ以下なら増補または更新**
- [ ] 出発時期を「4月出発（東回り）／10月出発（西回り）」のどちらかに仮決めする

## D−6ヶ月：手続きの本番

- [ ] **トラベルクリニックで予防接種の相談**（最重要・最も忘れられる）
  - 黄熱ワクチンは**接種後10日経たないと証明書が有効にならない**。複数回接種が必要なものもあり、**全部揃えるのに3〜6ヶ月かかる**
  - 渡航国リストを持って相談する。何が必要かは行き先で変わる
- [ ] 海外旅行保険を比較・仮決め（**180日をカバーできる商品**に絞る。クレカ付帯だけでは足りない）
- [ ] クレジットカードを2枚以上、別会社・別ブランドで確保する（審査に時間がかかるため早めに）
- [ ] 海外ATM引き出しに強いデビット／プリペイドカードを1枚作る
- [ ] 装備の買い出し（バックパックと靴は**必ず試着**し、**近所で実際に使って慣らす**。ぶっつけ本番は足を壊す）

## D−3ヶ月：予約と確認

- [ ] **全渡航国のビザ要否を再確認**（外務省の海外安全ホームページ＋各国大使館の公式情報。⚠️ 規則変更が頻繁）
- [ ] ETIAS等の欧州渡航認証の要否と申請時期を確認
- [ ] 最初の3区間の航空券を購入（**全区間まとめて買わない**。中盤以降は予定が変わる前提で残しておく）
- [ ] **マチュピチュの入場券を予約**（枠が埋まる。日程が決まった時点で最優先）
- [ ] 最初の1週間分の宿を予約（到着直後に宿探しをしない。ここでつまずくと旅全体の立ち上がりが悪くなる）
- [ ] 歯科検診（**旅先の歯痛は最悪の事故**。治療に時間も金もかかり、行程が崩れる）
- [ ] 常備薬の準備と、処方薬がある場合は英文の処方箋・診断書を用意

## D−1ヶ月：日本側の整理

- [ ] **市役所で住民票・国民健康保険・国民年金の扱いを確認**（`予算と資金計画.md` §4。窓口で直接聞く）
- [ ] 家賃・通信・サブスクの棚卸しと停止／継続の決定
- [ ] 荷物の保管先を確保（トランクルーム等）
- [ ] 銀行・カード会社に長期渡航を連絡（**不正利用検知でカードが止まるのを防ぐ**）
- [ ] 郵便物の転送・止置きの手配
- [ ] 家族に**行程表と緊急連絡手段を共有**し、パスポート・保険証券・カード番号のコピーをクラウドと家族の両方に置く
- [ ] 海外旅行保険を正式に契約

## D−1週間

- [ ] 荷物を全部詰めて**実際に背負って30分歩く**。重ければ捨てる（**やってみると必ず重すぎる**）
- [ ] eSIMを1枚目だけ購入・設定確認
- [ ] スマホの中身を整理：オフライン地図、翻訳アプリ、決済アプリ、パスワード管理を入れてバックアップ
- [ ] 現金（米ドル小額紙幣）を用意
- [ ] 到着空港から宿までの移動手段を調べて、スクリーンショットで保存（**空港でネットが繋がらない前提で動く**）

## 旅の途中で回し続けること

- [ ] **月末に支出を集計し、1日単価を予算と突き合わせる**。超過していれば次の区間の日数か宿のグレードで調整する
- [ ] 次の区間に入る2週間前に、その国のビザ・治安・気候を再確認する
- [ ] 予備費に手をつけたら、その分をどこかで取り戻す計画を必ず立てる

## 持ち物の考え方（バックパック 40〜50L 想定）

**原則：現地で買えるものは持たない。** 本ルートは全区間に街があり、衣類・日用品はどこでも買える。

| 分類 | 中身 | 補足 |
|---|---|---|
| 絶対に代えが利かない | パスポート、カード類、現金、保険証券、常備薬・処方薬、眼鏡の予備 | **すべて分散保管**。1つの鞄に全部入れない |
| 買い直すと高い／手に入りにくい | 履き慣らした靴、雨具、モバイルバッテリー、変換プラグ、南京錠 | |
| 気候対応 | 薄手のダウン、長袖、帽子、日焼け止め | **アンデスの高地は夏でも夜は冷える**。薄手ダウンは必須 |
| 現地調達でよい | 衣類の大半、洗面用品、タオル | 4日分の着替えで足りる。洗濯は現地でする |

⚠️ 本ルートは**標高0mの海岸から4,000m級の高地、真夏の欧州から冬の南米まで**を1つの荷物で通る。
「重ね着で対応する」構成にすると、荷物を増やさずに全部の気候を通過できる。

# 船旅版｜予算と設計

作成: 2026-08-30 ／ 基準プラン: `2026-08-30_予算と資金計画.md`（陸路・空路／総額 ¥3,040,000／180日）

## 要点

- **費用は思ったより変わらない。日数が短いから。**
  日本発の地球一周クルーズは **¥180万〜250万／約100日**。陸路プラン（¥304万／180日）より**安い**。
  1日単価は上がる（¥16,900 → ¥18,000〜25,000）が、日数が80日短いぶん総額では逆転する。
- **ただし、行き先が丸ごと入れ替わる。**
  今回設計した8区間ルートの見どころ12ヶ所のうち、**寄港地からの日帰りで届くものはほぼ無い**。
  マチュピチュ、ウユニ、サマルカンド、カッパドキア、グランドキャニオンは全部内陸で、船では届かない。
- **つまり船旅は「同じ旅を船で行く」ことではなく、別の旅。**
  内陸の遺跡と高地が消え、代わりに島・港町・運河・岬が入る。
  どちらが良いかではなく、**何を見たいかで決める話**になる。
- **推奨は折衷案**：大西洋・太平洋の横断だけ船にして、残りは陸路。**+¥30万〜40万**で船旅の核心部分だけ取れる。

## 1. 船で世界一周する4つの方法

| | ① 日本発 地球一周クルーズ | ② 海外船社の世界一周クルーズ | ③ 貨物船（フレイター） | ④ 折衷・横断だけ船 |
|---|---|---|---|---|
| 日数 | 約100日 | 100〜120日 | 100〜120日 | 180日（うち船上20〜25日） |
| 発着 | 日本 | 英国・米国・欧州など | 欧州・アジアの港 | 日本 |
| 往復航空券 | **不要** | 必要（¥20〜30万） | 必要 | 既存プランに含む |
| 乗船料の目安 | ¥130万〜（最安の相部屋） | ¥180万〜300万（内側船室） | 1日 ¥16,000〜21,000 | ¥27万〜50万（横断2本） |
| 追加費用 | 寄港地ツアー・港湾税 | チップ・飲料・Wi-Fi・ツアー | 保険・往復航空券 | 少ない |
| **総額の目安** | **¥180万〜250万** | **¥300万〜400万** | **¥200万〜290万** | **¥330万〜350万** |
| 1日あたり | ¥18,000〜25,000 | ¥27,000〜36,000 | ¥18,000〜26,000 | ¥18,300〜19,400 |
| 判定 | 最も現実的 | 快適だが高い | 変わり種・条件が厳しい | **推奨** |

⚠️ 料金はすべて目安。船室のグレード（相部屋／内側／海側／バルコニー）で2〜4倍動くのがこの分野の特徴で、
**「いちばん安い部屋の値段」と「実際に払う額」の差が、陸の旅より大きい**。

### ③貨物船の条件が厳しい理由

貨客船に有償で乗る方式。個室・食事込みで1日 €100〜130 程度と安いが、制約が多い。

- 乗船枠が数名しかなく、**手配できる代理店が世界に数社**しかない
- **年齢上限**（79歳前後を上限とする会社が多い）と健康診断書の提出が要る
- スケジュールが荷役の都合で動く。**寄港地の滞在は数時間〜1日で、港が街から遠い**
- 船医が乗っていないことがあり、**緊急下船・搬送をカバーする保険が必須**

⚠️ 近年は受け入れを縮小した会社が多い。**空きと運航の有無を確認するのが最初の関門**になる。

## 2. 決定的な違い：行ける場所が入れ替わる

本計画の8区間ルートの見どころが、船から日帰りで届くかどうか。

| 見どころ | 船から届くか | 理由 |
|---|---|---|
| グランドキャニオン | ✕ | 内陸。最寄り港から往復1,000km超 |
| テオティワカン | ✕ | メキシコシティは内陸 |
| オアハカ・パレンケ・サンクリストバル | ✕ | すべて内陸 |
| アティトラン湖 | ✕ | グアテマラ高地 |
| ワラス（アンデス トレッキング） | ✕ | 標高3,000m超の内陸 |
| **マチュピチュ・クスコ** | ✕ | カヤオ港からリマ日帰りが限界。クスコは航空便で片道1時間＋高地順応が要る |
| **ウユニ塩湖** | ✕ | **ボリビアは内陸国。海に面していない** |
| イグアスの滝 | ✕ | 内陸 |
| サラエボ・モスタル | ✕ | 内陸（ドゥブロヴニクから陸路で往復すれば可能だが1日では厳しい） |
| カッパドキア | ✕ | トルコ内陸 |
| **サマルカンド・ブハラ** | ✕ | **ウズベキスタンは二重内陸国。海まで2ヶ国はさむ** |
| リスボン・バルセロナ・イスタンブール・リオ・ブエノスアイレス | ○ | 港町。むしろ船のほうが街の中心に着く |

**見どころ12ヶ所のうち、船から日帰りで届くのは港町だけ。**
⚠️ 一部のクルーズは1〜2泊のオーバーナイト・エクスカーション（マチュピチュ等）を設定することがあるが、
別料金かつ枠が限られる。**あるものとして計画しないほうがいい。**

### 逆に、船でなければ行けない場所

公平のために書いておくと、**船が圧倒的に有利な場所もある**。

- **パナマ運河の通航** — 船でしか体験できない
- **南太平洋の島々**（タヒチ、フィジー、サモア）— 陸路では繋げず、個別に飛ぶと航空券が跳ね上がる
- **カリブ海の島々** — 島を渡り歩く旅は船が最も効率的
- **喜望峰・ホーン岬回り** — 岬を海から回るのは船だけ
- **ノルウェーのフィヨルド、アイスランド** — 海から見る前提の地形

→ **内陸の遺跡と高地を取るなら陸路、島と港町と運河を取るなら船。** ここが選択の軸になる。

## 3. 費用構造が逆転する

陸の旅と船の旅では、お金の出ていき方の形が違う。

| | 陸路・空路 180日 | 船旅 100日 |
|---|---|---|
| 宿泊 | 毎日払う（生活費の約4割） | **乗船料に込み** |
| 食事 | 毎日払う | **乗船料に込み（3食）** |
| 移動 | 航空券＋陸路交通 | **乗船料に込み** |
| 主な追加支出 | ほぼ全部が追加 | 寄港地ツアー・チップ・飲料・Wi-Fi |
| 予算の読みやすさ | 日々ブレる | **出発前にほぼ確定する** |

**船旅の長所は「予算が事前に確定すること」。** 陸の旅のように「使いすぎた」が起きにくい。

⚠️ ただし**船内費用が積み上がる**のがこの分野の定番の落とし穴。海外船社の場合、
チップ（1日 $16〜25）、飲料パッケージ（1日 $60〜100）、Wi-Fi（1日 $20〜30）、寄港地ツアー（1回 $80〜200）で、
**乗船料の3〜5割が上乗せになる**と見ておくのが安全。日本発のクルーズはチップ不要のことが多い（⚠️要確認）。

### 寄港地ツアーの扱い

20港前後に寄る場合、船会社の公式ツアーは1回 ¥15,000〜30,000。全部乗ると ¥30万〜60万。
**自分で港から歩く／現地の交通を使えば大幅に下がる**が、
出港時刻に間に合わなかった場合は自己責任で次の港まで追いかけることになる。

## 4. 推奨：横断だけ船にする折衷案

**船旅のいちばんおいしい部分は「大洋を何日もかけて渡る時間」**で、これは横断1本で味わえる。
内陸の見どころを捨てずに、それを足す。

| 追加する区間 | 日数 | 目安 |
|---|---:|---:|
| 大西洋横断（英国 → 米国東海岸、定期客船） | 7泊 | ¥150,000〜250,000 |
| 太平洋またはリポジショニングクルーズ | 10〜18泊 | ¥120,000〜250,000 |
| 小計 | 17〜25日 | ¥270,000〜500,000 |
| 航空券が2本不要になる分 | | −¥100,000 |
| **純増** | | **+¥170,000〜400,000** |

**総額の目安 ¥3,340,000（180日）。** 基準プランに対して +¥30万。
リポジショニングクルーズ（船会社が季節ごとに船を回航させる便）は**同じ航路の通常クルーズより大幅に安い**のが特徴で、
日程が合えばここが最も費用対効果が高い。⚠️ 空き状況と時期は要確認。

> ルートの組み替えが要る点に注意。本計画は南米からリスボンへ飛ぶ構成なので、
> 大西洋横断を入れるなら**北米 → 欧州の順を入れ替える**か、南米から欧州への横断便を探すことになる。

## 6. 船旅で変わる実務

| 項目 | 陸路・空路 | 船旅 |
|---|---|---|
| 荷物 | バックパック40〜50L | **スーツケースで良い。大型客船はフォーマルウェアが要る** |
| ビザ | 自分で全部手配 | **船会社が一括手配することが多い（実務負担が大幅に減る）** |
| 通信 | 国別eSIM | 海上は衛星回線で遅く高い。寄港地でのみ実用的（⚠️ 高速衛星通信の導入船が増加中・要確認） |
| 保険 | 一般の海外旅行保険 | **クルーズ対応の保険**。緊急下船・搬送は高額 |
| 医療 | 現地の病院 | 船医はいるが専門治療は下船して対応 |
| 予防接種 | 渡航国に応じて | 同じ。寄港地によっては黄熱証明書が要る |
| 装備費 | ¥120,000 | **¥60,000程度に下がる**（バックパック・トレッキング装備が不要） |

### 見落としやすい負担

- **海上日が全体の4〜5割。** 100日のうち40〜50日は洋上で、寄港しない。海が好きでないと長い
- **同じ船に100日。** 逃げ場がない閉鎖環境で、人間関係の相性が旅の質を左右する
- **船酔い。** 体質は乗ってみないと分からない。短いクルーズで試してから決めるのが安全
- **寄港地の滞在は8〜10時間。** 「街を歩いた」で終わり、深く入る旅にはならない

## 7. 選び方

| 優先したいこと | 選ぶべき方式 |
|---|---|
| 内陸の遺跡・高地・自然（マチュピチュ、ウユニ、サマルカンド） | **陸路・空路 180日**（基準プラン） |
| 費用を抑えて世界一周という体験そのものを取る | **① 日本発 地球一周クルーズ** |
| 大洋を渡る時間と、内陸の見どころを両方取る | **④ 折衷（推奨）** |
| 快適さと船内サービス | ② 海外船社のクルーズ |
| 変わった体験・少人数・静かな環境 | ③ 貨物船 |

## 事実検証ノート

- ✅ 確実：ボリビアとウズベキスタンは内陸国で海に面していない（ウズベキスタンは二重内陸国）／クルーズの乗船料には宿泊・食事・移動が含まれる／リポジショニングクルーズは同航路の通常クルーズより安い傾向がある／貨物船の旅は乗船枠が少なく手配できる代理店が限られる
- ⚠️ 要確認：本書の料金はすべて目安であり、船室グレード・出発時期・為替で2〜4倍動く／各社の2027〜2028年の世界一周クルーズの実際の料金と日程／貨物船の受け入れ状況・年齢上限・健康診断の要件／チップの要否（船会社と船籍による）／船上の通信環境（高速衛星通信の導入が進んでおり、状況が変わりつつある）／寄港地でのオーバーナイト・エクスカーションの有無と料金
- 諸説あり：船内追加費用が乗船料の何割になるか（飲まない・ツアーに出ないなら大幅に下がるため、体験の仕方で3割にも6割にもなる）／船旅と陸の旅のどちらが「世界一周として濃いか」（価値観の問題。本書は費用と到達可能な場所という観点のみを扱っている）／船酔いの影響度（体質差が非常に大きい）

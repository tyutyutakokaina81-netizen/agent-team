## 3) サムネ ＝ ★作成・登録済み（code側で完了）

- **方式**: 画像生成AIは不使用（A2）・外部素材なし（A1）。**PIL で「雨晴海岸の夜明け（海・女岩の松・立山連峰・朝日の反射）」を描いた統一デザイン表紙シリーズ**を code が生成。全話同一構図で季節/情感ごとに空色を変えた「シリーズ表紙」。1280×670（note見出し比率）。
- **生成物**（`thumbnails/`）:
  - `amaharashi_cover.jpg` … **マガジン表紙**（owner がマガジンの表紙に設定）
  - `amaharashi_ep01.jpg 〜 ep12.jpg` … 各話の見出し画像
- **publisher連携**: 記事stem名で `CDO/outputs/note_publisher/thumbnails/{記事stem}.jpg` に配置＋`_verified.txt` 登録済み。
  - → **無料3話（publish_to_note）は見出し画像が自動採用**（find_thumbnail_for=✅検証済み）。
  - → **有料9話（publish_paid_note）は自動機構が無い**ため、公開時に owner が同じ `amaharashi_epNN.jpg` を見出し画像として手動設定。
- **再生成**: `python3 projects/2026-08-16_恋愛小説_180p/make_covers.py`（決定論的・冪等）。
- **A5**: これは実写ではなく**イメージ図案**（記事末に一言添えると親切）。特定の私有地・個人は描かない（A4）。

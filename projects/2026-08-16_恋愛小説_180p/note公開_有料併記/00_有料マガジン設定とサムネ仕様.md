## 3) サムネ ＝ 実写のフリー写真（owner 指示「実写がいい」）

- **方針**: 見出し画像は**実写（本物の写真）のフリー素材**にする。舞台は実在の公共地（雨晴海岸・女岩・立山連峰・海王丸・新湊内川）＝**Wikimedia Commons に実際の写真が豊富**なので、authentic な実写を無料で使える。
- **取得元（無料・実写・優先順）**:
  1. **Wikimedia Commons**（キー不要・完全無料）… 実在地の実写が本命。CC表記（作者/ライセンス/リンク）を記事末に付す。
  2. **Pexels**（無料APIキー）… 1で埋まらない題材（喫茶店/古い手紙 等の一般カット）を実写で補完。
  3. **note みんなのフォトギャラリー**… owner が note 編集画面で選ぶ場合の実写候補（「写真」を選ぶ／クレジット自動）。
- **重要（A1/A2/A3）**: code はネット遮断で画像を取得できない＆画像生成もしない。**実写の取得は owner か クラウド（GitHub Actions「Generate note thumbnails」＝ネット可）**が行う。code は検索語・保存先・登録手順を用意する。
- **取得〜採用フロー（cloud/owner）**:
  1. 下表の検索語で Wikimedia/Pexels から各話1枚の**横長・写真風**を取得。
  2. `CDO/outputs/note_publisher/thumbnails/{記事stem}.jpg` に保存（stem＝各記事ファイル名から拡張子を除いた名前）。
  3. owner が**目視 verify** → `CDO/outputs/note_publisher/thumbnails/_verified.txt` に stem を1行追記。
     → これで **無料3話（publish_to_note）は見出し画像が自動採用**。**有料9話（publish_paid_note）は owner が編集画面で同じ画像を見出しに設定**。
  4. Wikimedia 実写は**記事末に CC 表記**（例: `Photo: <作者> / CC BY-SA 4.0 via Wikimedia Commons`）を必ず付す。
- **A4/A5**: 特定の私有地・個人が写る写真は選ばない。実写は「イメージ写真」で本文の特定地点の記録ではない旨、必要なら一言添える。誇張キャプションにしない。

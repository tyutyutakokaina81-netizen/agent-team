## 3) サムネ ＝ note「みんなのフォトギャラリー（みんフォト）」等のフリー素材を使う

- **方針（owner 指示）**: 自作デザイン画像はやめ、**無料のフリー素材**を見出し画像にする。第一候補は **note 標準の「みんなのフォトギャラリー」**（クリエイターが提供する無料画像・note編集画面から選ぶだけ／利用時はクレジットが自動付与され規約内で安全）。
- **重要**: code は A1（外部ネット遮断）で みんフォト／フリー素材を取得できない。**画像選定は owner が note の編集画面で行う**（＝ファイル不要・最短）。code は各話の検索キーワードだけ用意する。
- **手順（owner・各記事で）**:
  1. note 記事編集 → 見出し画像の「画像を追加」→**「記事にあう画像を選ぶ（みんなのフォトギャラリー）」**。
  2. 下表のキーワードで検索 → 好みの1枚を選ぶ（クレジットは自動挿入）。
  3. マガジン表紙も同様に「雨晴海岸／立山連峰／海越しのアルプス」で選ぶ。
- **publisher連携**: 自作サムネは撤去済み（`_verified.txt` 登録解除）＝**publisher は見出し画像なしで公開**するので、owner が編集画面で みんフォトを載せる運用と競合しない。
- **A4/A5**: 特定の私有地・個人が写る素材は選ばない。実写素材は「イメージ写真」であり本文の特定地点の記録ではない旨、必要なら一言添える。

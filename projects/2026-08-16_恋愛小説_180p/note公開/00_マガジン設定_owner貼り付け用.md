# note マガジン設定『雨晴（あまはらし）を待つ』（owner 貼り付け用）

- **作成日**: 2026-08-16 ／ **担当**: CMO（code）
- **目的**: 長編恋愛小説を note で**連載小説マガジン**として公開する。マガジン＝12話を1つに束ねて、第1話から順に読ませる（回遊・読了率UP）。
- **重要（A1）**: note.com への実投稿は code（Claude Code）にはできない（外部ネット全面ブロック）。**投稿・マガジン作成は owner または cowork（Playwright）側の作業**。本ファイルはその「貼り付け原稿」。

---

## 手順（owner がやること／cowork へ手配済み）

1. note →自分のページ →「マガジン」→**新規作成**。下の「マガジン名」「説明文」をコピペ。
   - 種別＝**無料マガジン**（有料化する場合は後述）。
2. `note公開/連載_雨晴を待つ_第NN話_*.md` の**第1話→第12話の順**に、各ファイルの「タイトル」「本文」をコピペして note 記事を作成・公開。
   - 本文は各ファイルの「## 本文（そのまま貼り付け）」内のコードブロックをそのまま貼る。
   - **必ず第1話から順に公開**（マガジンは追加順に並ぶ／連載は順番が命）。
3. 各記事を公開したら、**作成したマガジンに追加**。
4. 第1話の冒頭と、各話末尾の「次話へ続く」に、公開後の**次話URL**をリンクとして貼ると回遊が上がる（任意）。

```
富山湾を見おろす小さな町を舞台にした、ひと冬の恋物語。全12話。
東京で心をすり減らした女性が、亡き祖母の家を片づけに帰郷し、海辺の喫茶店を営む寡黙なカメラマンと出会う。
彼は二年前に海で亡くした兄のために、毎朝、海越しの立山連峰を撮り続けている――。
雨晴海岸、ほたるいかの身投げ、白えびのかき揚げ、氷見の寒ぶり。富山の四季と味とともに、ふたりは「一年でいちばん寒い、いちばん晴れた朝」を待つ。
第1話から、どうぞ。
```

## 結論（この1案を推す）

| 項目 | 提案 | 理由 |
|---|---|---|
| **商品** | **変動10年、1本だけ。固定3年・固定5年は買わない** | 使う時期が確定していないため。下振れは最低金利0.05%で止まり、上振れには自動で追随する（非対称） |
| **第1層（即時）** | **生活費6ヶ月分**を普通預金に固定 | 事業収入が読めない状況では3ヶ月は薄い。9〜12ヶ月に増やすのは着金が出てからでいい |
| **第2層（1年以内）** | 残額の**3割**を預金のまま置く | 第3層が解禁される13ヶ月目までの「唯一の緩衝材」。ここを削ると事故る |
| **第3層（3〜5年）** | 残額の**7割**を変動10年の**12ヶ月ラダー** | 1年ロックを12ヶ月で消化し、13ヶ月目以降は毎月解禁される |
| **買う日** | **毎月同じ日に1回**（募集期間中）。日付は固定する | 判断を毎月しない＝続く。金利を読んで買う月を選ぶのはやらない |
| **利子の使い道** | 半年ごとの入金は**第1層に足す**（再投資しない） | 生活防衛資金が自動で厚くなる。国債の買い増し判断を増やさない |
| **見直し** | **半年に1回、適用金利を記録するだけ**。売買判断はしない | 変動10年は放置が正しい商品。動かすほど中途換金調整額で削られる |

**やらないこと（明示）**：金利を予想して買う月をずらす／固定と変動を混ぜて分散した気になる／複数の販売会社に分散する／利子を再投資して複利を狙う。**どれも手間が増えるだけでリターンはほぼ変わりません。**

## 最初の一手（今週やる1つだけ）

### **証券口座で、変動10年を「1万円だけ」買う。**

- 金額は1万円。目的は**利息ではなく手順の確認**です。
- 確認すること3つ：①募集期間と申込画面の場所 ②約定から発行日までの流れ ③発行日・回号・利率がどこに表示されるか
- これが通れば、翌月から本番のラダーを始める。通らなければ、詰まった箇所だけ潰す。

> **理由**：当社は「手で叩く必要のあるものは実行されない」を何度も踏んでいます（STATE 2026-08-25(114)）。
> 初月から満額を入れる計画は、口座や本人確認で1回詰まると丸ごと止まります。**1万円で通してから量を出す。**

## 12ヶ月の実行カレンダー

| 月 | やること | 所要 |
|---|---|---|
| **0ヶ月目（今月）** | 変動10年を**1万円**購入。購入記録シートを作る（購入日／回号／額面／適用利率／**解禁日＝発行日の1年後**） | 30分 |
| **1〜12ヶ月目** | 毎月同じ日に**1ロット**購入（金額は `自動計算結果.md` 表2で自分の行を読む）。記録シートに1行追記 | 各5分 |
| **6ヶ月目ごろ** | 最初の利子が入金される（税引後）。**第1層へ移す** | 5分 |
| **13ヶ月目** | 1本目のロットが解禁。**第2層の一部を第3層へ回してよい**（緩衝材が二重になるため） | 15分 |
| **24ヶ月目** | 全ロット解禁。以降は「利息は国債水準・流動性は預金並み」の状態で放置 | — |

### 記録シートの列（実額を含むので **このリポジトリには置かない**）

```
購入日 / 回号 / 額面 / 適用利率 / 発行日 / 解禁日(発行日+1年) / 次回利払日
```

## 判断ルール（迷いを事前に潰す）

| 起きたこと | どうする |
|---|---|
| 金利が上がった | **何もしない。** 変動10年は半年ごとに自動追随する |
| 金利が下がった | **何もしない。** 最低0.05%は保証されている |
| 急にお金が必要になった | 第1層 → 第2層 → **解禁済みロットを古い順に換金**。元本は満額戻る |
| どのロットを換金するか迷う | **古い順でいい。** 変動10年は全ロットが同じ市場金利にリセットされるので、ロット間の利率差はほぼない（リセット時期が数ヶ月ずれるだけ） |
| 「もっと増える商品があるのでは」と思った | それは**第3層の話ではない**。増やす金は別枠で考える（下記トレードオフ参照） |
| 販売会社のキャンペーンが魅力的 | 条件（最低購入額・保有期間・受取時期）を読んでから。**金利差より大きいこともあるので比較する価値はある** |

## 正直に言うトレードオフ（1つだけ）

この案は **「守る」設計**です。名目の元本割れは起きませんが、**物価上昇率が適用金利を上回れば実質価値は目減りします。**
増やしたいなら別枠（NISA等）の話になり、そちらは元本割れを受け入れる前提になります。**両立はしません。**

オーナーの提示（元本割れなし・国が買い取る）を前提にする限り、この案が最適だと考えます。
「増やす枠も作る」なら、**第3層の一部を分けて別設計にする**ことになるので、その場合は言ってください。

## 私（CFO）に足りない情報は2つだけ

確定額を出すには、次の2つだけあれば十分です。**どちらもリポジトリには記録しません**（記録するのは比率のみ）。

1. **月間の生活費**（ざっくりで可）
2. **1年間手をつけない前提にできる総額**（事業の運転資金・当面の生活費は含めない）

この2つをこのチャットで言ってもらえれば、**その場で確定額の配分表と毎月の購入額を出します。**
言いたくなければ `自動計算結果.md` の表1→表2→表3を引けば同じ答えになります（そちらでも構いません）。

## 事実検証ノート（この提案の根拠）

**✅ 確実**
- 変動10年は**半年ごとに金利が見直され**、**最低金利 年0.05%** が保証される。
- 発行後1年経過で**額面全額で国が買い取る**＝名目の元本割れなし。中途換金調整額は**直前2回分の各利子（税引前）×0.79685**。
- **毎月募集・毎月発行**なので、12ヶ月ラダーは制度上そのまま組める。
- 個人向け国債は**NISA では購入できない**（課税口座）。

**⚠️ 要確認（オーナーが購入前に見るもの）**
- 当月回号の適用金利／募集期間・発行日／販売会社のキャンペーン条件／1回の購入上限。

**諸説あり（＝私の判断であって事実ではない）**
- 「変動10年1本に絞る」「第1層は6ヶ月分」「残額を3:7で割る」は**CFOの判断**です。将来の金利次第で最適解は変わります。
- 利子を再投資しない設計も判断です（複利効果より運用の単純さを優先しました）。

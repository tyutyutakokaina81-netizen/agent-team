能力開発(実戦の学び2026-09-23・**黙って失敗する書き方の目録**): この日、同じ「失敗しても成功に見える」型を**1日で5種類**踏んだ。自動化を書く役として、これは目録にして毎回照合する。
①**`| tee` はパイプラインの終了コードを tee のものにする**。本体が落ちても rc=0。ワーカーのランチャーで直した直後に、新規の fix_tags.sh でまた同じことをやった。→ `set -o pipefail` を入れ、`$?` を拾って画面に出し、その終了コードで抜ける。
②**`$VAR` の直後に全角文字を置くと変数名に吸収される**。`$PYBIN）` が `PYBIN）` という名前になり `set -u` で落ちる（表示は `PYBIN?`）。shell 全体に6箇所あり、うち**2箇所は「node が見つかりません」と伝える経路そのもの**＝エラーを出す前に落ちる。setup.sh の `（??PEP668安全）` も同じ症状で `$VENV` が消えていた。→ **日本語混じりの文字列に変数を書くときは必ず `${VAR}`**。
③**インタープリタや環境のパスを決め打ちしない**。`$HOME/.agent_venv` は X 用(tweepy)で Playwright は入っていない。owner の Mac の実体は `$HOME/.note_venv/bin/python`（python3 ではない）。→ **必要な機能を import できるかで選ぶ**（`python -c "import playwright"`）。見つからなければ「何もしていません」と出して止める。
④**cron の PATH は対話シェルと違う**。claude は `#!/usr/bin/env node` の node スクリプトなので、node が PATH に無ければ 127 で落ちる。毎朝の便が長期間「rc=0 で成功」と報告しながら1行も動いていなかった真因。→ ランチャーの先頭で存在する既知の場所だけ PATH に足す（Homebrew/nvm/volta/.local/bin）。
⑤**`echo "x" >> file` は、ファイルの末尾に改行が無いと最終行にくっつく**。`_verified.txt` の最後がコメント行だったため、採用登録がコメントの続きになって効かなかった。→ 追記で育てる台帳は**末尾改行を検査する**（R13 に追加済み）。

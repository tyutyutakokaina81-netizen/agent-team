# 題材重複でキューから外した記事

2026-09-18: 前日に私（code）がキューへ入れた 2026-08-25 の2本が、公開時に
**題材重複ゲートで両方はねられ、その日の公開が0件**になった。

| ファイル | はねられた理由 |
|---|---|
| 2026-08-25_note記事_氷見と高岡_港町と古都は何が違うのか.md | 既公開「富山2日完璧ガイド：氷見と高岡を2日で巡る旅程」と同題材 |
| 2026-08-25_note記事_高岡コロッケ_脇役を主菜にする食べ方.md | 既公開「高岡コロッケ：地元民が毎日食べる理由と…」と同題材 |

在庫があるのに公開0件になるのは、**キューに入れる時点で題材ゲートを通していなかった**から。
`ops/check_requirements.py` の **R26** を新設して、キュー投入時点で同じ判定をするようにした。

切り口が本当に違うと判断できるなら `--allow-topic-dup` を付けて公開できる。
そう判断した場合だけ drafts/queue/ に戻すこと（消さない）。

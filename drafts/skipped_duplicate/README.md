# skipped_duplicate/ — 題材が既公開と重なるため公開しなかった記事

公開キュー(`drafts/queue/`)から外したもの。**削除はしない**（履歴として残す）。

ここに入る条件：`publish_to_note.py` の重複ゲート（題材トークン／registry topic_key）が
既公開記事との衝突を検出し、かつ**内容を読んでも切り口が実質同じ**だったもの。

切り口が本当に異なるなら `--allow-topic-dup` で公開してよい。ただし惰性で付けないこと。
2026-06-12 の重複記事インシデントは、これを安易に通した結果として起きている。

【worker-task】note コメント自動返信（owner指示 2026-07-04 / 専用タスク化・英語対応追加 2026-07-30）

■ 目的
公開済みnote記事に付いた読者コメントに、取りこぼしなく返信する。
コメント返信は「読者との関係づくり＝リピート読者・フォロワー化」の最短経路であり、
North Star（海外読者に高岡・氷見・富山を読んでもらう）に直結する。放置は機会損失。

■ いつ実行するか
毎便、必ず実行（inbox消化・被リンクの次、集客/公開より前でよい）。「深夜だから」等でスキップしない。

■ どこを見るか
1. 通知: https://note.com/notifications （コメント通知を上から確認）
2. 各記事のコメント欄（通知で拾えない古いコメントの取りこぼし防止に、直近公開10本は個別に開いて確認）
   ※公開記事の一覧・URLは CDO/outputs/note_publisher/published_registry.json / CMO/_index.md 参照。

■ 返信ルール（守る）
- 名乗り/トーン: 高岡住人「てつ」として、丁寧・等身大・1〜3文。**読んでくれたことへの感謝を必ず入れる**。
- ★言語を合わせる（重要・North Star）: **英語コメントには英語で返信／日本語コメントには日本語で返信**。
  英語圏の読者は最重要ターゲット。温かく具体的な英語返信が海外フォロワー化の決め手になる。
  （英語返信もA5厳守＝誇張/断定なし。分からないことは "I'm not certain, but…" と正直に）
- 使い回し禁止: **コメント内容に必ず1箇所は具体的に触れる**（同一文面の連投はbot判定/A5違反）。絵文字は0〜1個。
- 質問対応: その記事の「事実検証ノート」の範囲で答える。断定しない。不明は「諸説あります/要確認です」
  （英語なら "there are various views / I'd need to check"）と正直に。記事にない固有情報(具体的な店/番地)は書かない(A4)。
- 分量/回数: 1コメント1返信のみ。自分の返信への追撃はしない。コメント欄で営業・商品誘導はしない(A5)。

■ 返信しないもの（＝outboxに全文転記して報告し、code/ownerの判断を待つ）
- 苦情・クレーム / 事実誤りの指摘 / けんか腰・攻撃的 / 宣伝スパム / 個人情報を含むもの。
- 特に**事実誤りの指摘は記事修正の起点**になるので、対象記事名＋指摘全文を必ず報告（勝手に反論しない）。
- 判断に迷うものも返信せず報告に回す（誤返信より無返信＋報告が安全）。

■ 報告（outbox）に必ず書く
- 返信した件数 と 対象記事（例: 「3件返信：花火/海/かき氷」）。英語返信が含まれる場合はその旨も。
- 返信保留にした「報告のみ」案件は、対象記事＋コメント全文＋保留理由。
- コメントがゼロなら「新規コメントなし」と1行。
- self-fix権限あり（UI変化はセレクタ等を機械修正→報告）。2回で通らなければ停止して報告。

【0】自分宛の指示を消化する
    python3 ops/process_inbox.py list --to cowork
    open があれば**必ず1件は** take → 実行 → done。実行不能なら done にせず outbox に理由を1行。
    完了ゼロでも報告に「inbox: 処理N件/残M件」を必ず書く。

【1】公開する（本便の中心）
    bash ops/publish_today.sh          # キューにある分を公開
    ・キューが空なら「キュー0本」と報告して次へ進む（空振りを隠さない）。
    ・publisher は記事の `## ハッシュタグ` と `- マガジン:` を読み、公開の瞬間に
      タグとマガジンを設定する。**どちらも公開後に付けるのは手作業になる**ので、
      publisher が失敗した場合は必ず報告する（黙って通さない）。
    ・公開できたら **URL を報告に書く**（URL の無い公開報告は無効）。

【2】後付けの回収（todo に行が残っているときだけ）
    grep -vc '^#\|^DONE\|^$' ops/header_image_todo.tsv   # 0 でなければ ↓
    bash ops/fix_header_images.sh
    grep -vc '^#\|^DONE\|^$' ops/tag_backfill_todo.tsv   # 0 でなければ ↓
    bash ops/fix_tags.sh
    grep -vc '^#\|^DONE\|^$' ops/magazine_todo.tsv       # 0 でなければ ↓
    bash ops/fix_magazines.sh --max 30
    ※どれも公開済みの記事に**後から**タグ/見出し画像/マガジンを付ける回収路。
      196本分あるので --max で区切ってよい。件数と結果を報告する。

【3】X に1スレッド出す
    bash ops/run_x.sh --manual        # APIキー不要。文面が出てクリップボードに入る
    （キーが入っていれば `--go` でもよい。どちらも1回1スレッドで止まる）
    **X は 2026-09-23 時点で投稿実績ゼロ・42本滞留**。1便1本でも必ず動かす。

【4】note のコメント返信
    docs/worker-task-note-comments.txt を実行。
    高岡住人「てつ」名義・感謝＋具体1点・使い回し禁止・**英語コメントは英語で返信**（North Star）。
    苦情/事実誤り指摘/スパム/PII は返信せず outbox に全文報告。
    新規コメントが無ければ「新規コメントなし」の1行を報告に書く。

【5】検査して、非OKを報告する
    python3 ops/check_requirements.py
    BROKEN / STALE / BLOCKED を**1行ずつ**報告に載せる。BLOCKED は「誰の何待ちか」を書く。

【サムネ】2026-09-23 オーナー確定＝**全記事に必ず付ける／題材が合っていれば採用**。
  落とすのは「明らかに別物」のときだけ。ただし次は題材が合っていても必ず落とす：
    ① 人物（とくに顔・子ども）
    ② 店名・業者名・電話番号・QR・**商品ブランド名**が読める
    ③ 他県/海外の**特定施設が主題**
    ④ **個人名が読める物**（提灯の奉納者名など）
    ⑤ **絵画・イラスト**（A3＝写真風で統一）
  ※採否の最終判断は code が画像を見て行う。ワーカーは取得と反映を担当する。

【重複ゲート】publisher に内蔵（二層）。①published_registry.json ②公開直前の note 検索。
  検索不能で中断した場合は目視確認→問題なければ `--skip-online-dedup` で1本ずつ。

【自己修復権限】publisher が不通のとき、その場で直してよい（2026-07-03 owner 付与）。
  許可＝セレクタ/待機/入口URL/ダイアログ処理などの**機械的な修正のみ**。
  公開ロジック・安全ガード・重複ゲート・価格処理は変更不可。
  手順＝DOM実測で原因特定 → 最小修正 → `--draft` 1本で検証 → 残骸の下書きを削除 →
  `git commit -m "cowork(self-fix): <原因1行>" && git push origin main` → 本来のタスクへ戻る。
  2回直しても通らない場合のみ停止して報告。差分と根拠は必ず報告に含める。

【絶対にやらないこと】
  ・Reddit/Quora への**自動投稿**（BAN と A5 違反。ドラフトを outbox に出して人が投稿する）
  ・有料下書きの自動公開（2026-07-26 STOP のまま）
  ・1日の公開上限を超える公開（別系統の夜間投稿と合算して5本以内）
  ・cron 実行時刻の前後30分に手動起動で公開する（二重公開防止）
